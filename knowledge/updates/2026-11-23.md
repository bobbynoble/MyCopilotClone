# Knowledge refresh — 2026-11-23

## Headlines
- Microsoft Learn now calls the new build model the **Microsoft Copilot harness** (we had "GitHub Copilot harness"). A third option, the **Customer Conversation harness** (preview), targets contact-centre style speech/chat agents.
- **Work IQ is GA** and on by default for new Microsoft Copilot harness agents (write operations on by default, so review permissions). Standard agents can be **upgraded to the new harness** (preview) with a migration report.
- Agents can now be **exposed through MCP and A2A channels** (preview), run from **event triggers**, and have **their own account/identity** (preview). Governance checklists should treat these as new identities and entry points.
- Devaney's new **hooks** method: a workflow that runs before a tool call to enforce rules the instructions can't (e.g. allow-listed SharePoint lists).
- pac CLI **2.16.1** is out (previously noted 2.13.1). Not installed.
