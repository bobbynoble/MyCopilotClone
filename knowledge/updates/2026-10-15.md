# Knowledge refresh — 2026-10-15 (baseline)

## Headlines
- Copilot Studio now has two build models: the **GitHub Copilot harness** (new experience with
  skills, memory, Work IQ and MCP/workflow tools; production-ready preview) and the standard harness.
- **Workflows with AI nodes** (Agent, Extract, Prompt, Human review, Copilot) are now the main way
  to build document and approval processes. Devaney's last six weeks of posts are all about this.
- Devaney's core method: **deterministic logic for rules, narrow agents for fuzzy work, parallel
  branches, structured outputs with fixed choices, and a human review step with an audit trail.**
- Governance changed: Entra Agent ID is mandatory (July 2026), Agent 365 is available, and billing
  is in Copilot Credits.
- pac CLI **2.13.1** is available. The installed version is 2.9.3.
